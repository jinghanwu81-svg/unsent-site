# 未寄出 · Unsent

**有些话，先留在这里。**

未寄出是一个面向手机的情绪表达与陪伴产品原型。无论是想联系某个人、还有话没有说完，还是只想整理一下心情，都可以先在这里写下来，给自己留一点做决定的时间。

## 三个空间

### 信箱：安放没有发出去的话

- 写一封新信，设置标题，保存为未寄出的信。
- 关闭编辑窗口时保留草稿，之后可以继续编辑。
- 按全部、未寄出、草稿筛选信件。
- 从对话中将自己写下的话整理到信箱。

### 说说：承接此刻的心事

默认进入对话页，可选择三种陪伴方式：

- **听我说说**：给表达留出空间。
- **安慰一下**：获得温和的回应。
- **一起想清楚**：借助问题梳理想法。

当前为交互 Demo，回复使用本地预设文案，**尚未接入 AI 模型**。切换方式可以体验不同的示例回应，不能代表真实的上下文理解能力。对话本身刷新后会重置，需要保留的文字可主动收进信箱。

### 小灯：看见每天的记录

在日历中手动记录想联系 TA 的冲动次数。每个日期的小灯根据当日记录显示不同亮度：

| 当日冲动次数 | 小灯状态 |
| --- | --- |
| 0 次 | 最亮 |
| 1–2 次 | 中亮 |
| 3–5 次 | 微亮 |
| 6 次及以上 | 熄灯 |
| 未记录 | 虚线轮廓 |

支持月份切换、选择日期、记录一次冲动和首次确认零次。未来日期不可记录，未记录不会自动算作零次。当前版本不提供更正或删除日历记录的界面。

小灯记录的是用户主动填写的**冲动次数**，不是聊天条数，也不会读取或监测真实的联系行为。亮度只反映设定的次数分档，不代表对个人的评价。

## 视觉与交互

采用中文界面、暖白纸色、嫩绿与淡紫配色，搭配手绘感小信封和暖黄色灯泡。底部固定三个导航入口：**信箱 / 说说 / 小灯**。桌面浏览时以手机宽度展示，小灯页按视口高度安排一屏布局。

## 本地体验

项目使用原生 HTML、CSS 和 JavaScript，无需安装前端依赖或构建。

在项目目录启动一个静态服务器，例如：

```sh
python -m http.server 8001 --bind 127.0.0.1
```

打开：

- 首页：`http://127.0.0.1:8001/`
- 信箱：`http://127.0.0.1:8001/chat.html#mail`
- 说说：`http://127.0.0.1:8001/chat.html#talk`
- 小灯：`http://127.0.0.1:8001/chat.html#calendar`

`index.html` 与 `chat.html` 都是完整入口。可部署到支持静态文件的网站托管服务。

## 文件结构

```text
index.html   首页入口，默认显示「说说」
chat.html    三页 Demo 入口
mobile.css   手机端布局、配色与插画样式
mobile.js    页面切换、演示聊天与信箱逻辑
lights.js    小灯日历、次数分档与本地存储逻辑
lights.css   早期独立日历样式，当前入口不再引用
```

## 数据与当前范围

- 信件、草稿和小灯记录使用浏览器 `localStorage` 保存。
- 没有账号、后端、云同步或 AI 接口；本版本不会主动上传这些记录。
- 数据仅在同一浏览器、同一站点来源下可用。更换域名、端口、设备或浏览器不会自动迁移；本地预览记录不会随代码上传到 GitHub。
- 清除网站数据会导致本地记录丢失；当前没有导出或恢复功能，本地存储也不是加密保险箱。
- 提醒、奖励、自定义语气、长期对话记忆和真实 AI 对话属于后续探索方向，当前尚未实现。

这个版本用于体验和讨论产品流程，不提供诊断或治疗服务。
